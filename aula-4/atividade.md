Elicitação de Requisitos

## Aula 4

## Processo 1 - Registro de pedidos

### Requisito 1

**Requisito:**  
O sistema deve permitir que o vendedor registre os produtos e as respectivas quantidades solicitadas pelo cliente.

**Fonte 1:** Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

**Fonte 2:** Procedimento de registro de pedidos da empresa. Fonte não humana, categoria documentação.

---

### Requisito 2

**Requisito:**  
O sistema deve registrar os dados do cliente no momento da realização do pedido.

**Fonte 1:** Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

**Fonte 2:** Cadastro atual de clientes utilizado pela empresa. Fonte não humana, categoria sistema legado.

---

### Requisito 3

**Requisito:**  
O sistema deve registrar a forma de pagamento escolhida pelo cliente no momento do pedido.

**Fonte 1:** Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

**Fonte 2:** Política comercial sobre formas de pagamento aceitas. Fonte não humana, categoria documentação.

---

## Processo 2 - Cadastro e remoção de produtos

### Requisito 4

**Requisito:**  
O sistema deve permitir que o administrador cadastre novos produtos, informando seus dados necessários para identificação e venda.

**Fonte 1:** Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.

**Fonte 2:** Cadastro atual de produtos da empresa. Fonte não humana, categoria sistema legado.

---

### Requisito 5

**Requisito:**  
O sistema deve permitir que o administrador altere as informações cadastradas de um produto.

**Fonte 1:** Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.

**Fonte 2:** Procedimentos internos para manutenção do cadastro de produtos. Fonte não humana, categoria documentação.

---

### Requisito 6

**Requisito:**  
O sistema deve permitir que o administrador remova produtos que não são mais comercializados.

**Fonte 1:** Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.

**Fonte 2:** Política interna de manutenção do catálogo de produtos. Fonte não humana, categoria documentação.

---

## Processo 3 - Controle de estoque

### Requisito 7

**Requisito:**  
O sistema deve permitir que o time de estoque registre a entrada de produtos e suas respectivas quantidades.

**Fonte 1:** Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.

**Fonte 2:** Notas fiscais e documentos utilizados para registrar a entrada de mercadorias. Fonte não humana, categoria documentação.

---

### Requisito 8

**Requisito:**  
O sistema deve registrar a baixa da quantidade de produtos no estoque quando ocorrer uma venda.

**Fonte 1:** Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.

**Fonte 2:** Sistema utilizado atualmente para controle de estoque. Fonte não humana, categoria sistema legado.

---

### Requisito 9

**Requisito:**  
O sistema deve permitir que o time de estoque consulte a quantidade disponível de cada produto.

**Fonte 1:** Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.

**Fonte 2:** Relatórios atuais de controle de estoque. Fonte não humana, categoria documentação.
