# Atividade - Sua vez de criar um caso

## Disciplina

Elicitação de Requisitos

## Aula 6

---

## 1. Empatia

**Pergunta:** Por que eu às vezes esqueço de entregar trabalhos da faculdade mesmo sabendo a data de entrega?

---

## 2. Definição

Eu esqueço de entregar alguns trabalhos porque tenho várias atividades e compromissos durante a semana, e nem sempre lembro de verificar as datas de entrega de cada atividade.

---

## 3. Ideação

1. Criar um aplicativo que envie notificações alguns dias antes da data de entrega de cada atividade.

2. Criar um calendário acadêmico que mostre todas as atividades organizadas por data de entrega.

3. Criar um sistema que envie um resumo semanal com as atividades que precisam ser entregues nos próximos dias.

---

## 4. Escolha

A ideia escolhida foi criar um aplicativo que envie notificações alguns dias antes da data de entrega de cada atividade.

Essa ideia foi escolhida porque permite que o aluno seja avisado com antecedência e consiga se organizar para realizar a atividade dentro do prazo.

---

## 5. Histórias de usuário

### História de usuário 1

Como aluno, quero cadastrar uma atividade com sua data de entrega, para conseguir organizar minhas tarefas acadêmicas.

### História de usuário 2

Como aluno, quero receber uma notificação antes da data de entrega de uma atividade, para não esquecer de realizar a tarefa.

### História de usuário 3

Como aluno, quero visualizar minhas atividades próximas do prazo, para saber quais tarefas preciso realizar primeiro.

---

## 6. Critérios de aceitação

### Critério de aceitação 1

**Dado** que o aluno cadastrou uma atividade com uma data de entrega,  
**Quando** salvar a atividade,  
**Então** o sistema deverá registrar a atividade e sua data de entrega.

### Critério de aceitação 2

**Dado** que existe uma atividade cadastrada com data de entrega próxima,  
**Quando** chegar o período definido para o aviso,  
**Então** o sistema deverá enviar uma notificação ao aluno.

### Critério de aceitação 3

**Dado** que o aluno possui atividades cadastradas,  
**Quando** acessar a lista de atividades,  
**Então** o sistema deverá apresentar as atividades organizadas de acordo com suas datas de entrega.
